 Conclusion

In this chapter, we learned two important concepts of Python: Parallel Programming and Object-Oriented Programming (OOP)

First, we explored different ways of executing tasks using **serial execution, multithreading, and multiprocessing. We observed that serial execution runs tasks one after another, which can take more time for large workloads. Multithreading allows multiple threads to run concurrently, while multiprocessing creates separate processes that can utilize multiple CPU cores. By comparing their execution times, we gained an understanding of how different execution models affect program performance and efficiency.

We also learned the basics of classes and objects in Python. We created classes, defined attributes and methods, and instantiated multiple objects from the same class. We studied the difference between class variables and instance variables, and saw how changes to each affect different objects. Furthermore, we explored inheritance, where a child class can reuse functionality from a parent class, helping to reduce code duplication and improve code organization.

Overall, this chapter provided practical experience with writing Python programs that are both efficient and well-structured. We learned how to improve performance using concurrency techniques and how to organize code using object-oriented principles such as classes, objects, variables, methods, and inheritance. These concepts form an important foundation for developing larger and more scalable software applications.
